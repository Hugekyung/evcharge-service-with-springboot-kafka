Root cause reproduced (red)
Scenario: KafkaTemplate.send blocks for one second before it returns an unacknowledged future.
Invocation:
  ./gradlew test --tests com.example.charging.kafka.ChargingEventProducerTest
Binary observable: FAILED, exactly one failing test:
  keepsTheWholePublishAttemptWithinThreeSecondsWhenSendingBlocksBeforeReturningAFuture()
  java.lang.AssertionError at ChargingEventProducerTest.java:131
Reason: the former implementation applied get(3, SECONDS) only after send returned, so the test ran for about four seconds.

Production repair
- A monotonic three-second deadline starts before KafkaTemplate.send.
- The future wait receives only the time left before that deadline.
- spring.kafka.producer.properties.max.block.ms=3000 bounds Kafka producer work that occurs inside send before its future is returned.
- InterruptedException still restores the interrupt flag and becomes ChargingEventPublishException.
- Kafka runtime send failures, including a pre-future broker timeout, become ChargingEventPublishException and therefore the controller's HTTP 503 mapping.
